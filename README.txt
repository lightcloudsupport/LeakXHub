LeakXHub website
================
- index.html is the whole site (all pages, logo, photo and styles are inside it).
- Upload it to any static host (GitHub Pages, Netlify, Cloudflare Pages, Vercel) or your own web hosting.
- Pages are reached with #leaks, #paid, #free and #about at the end of the link.
- Live Discord status uses the free Lanyard service (api.lanyard.rest).
  Join discord.gg/lanyard with your account so it can see your status.
  Change the user ID near the bottom of index.html (UID) to use a different account.
